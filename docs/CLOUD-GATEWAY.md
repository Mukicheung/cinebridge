# 云端检索网关接入

目标：共享检索不依赖开发者家中的电脑和网络；开源客户端不持有私有来源的地址、目录或凭据。

## 分工
- 开源客户端：Web、CLI、用户自己的豆瓣片单与 CD2 下载、通用网关连接器。
- 独立部署的私有服务：搜索和种子解析，服务端保管来源信息。
- 用户的电影文件：由自己的 115 / CD2 传输，不经过网关。

## 配置
在“设置 → 连接服务”选择“云端检索网关”，填写 HTTPS 网关地址与分配给自己的访问令牌。无需设置上游目录。令牌加密保存在本机，不从 Web API 返回。本地界面仍免登录。

CLI：
```sh
cinebridge connections add --kind gateway --name '云端检索' \
  --endpoint https://gateway.example --token-file /path/to/client-token
```

不要把上游凭据当成客户端令牌；每个用户的网关授权应独立发放和撤销。不要将令牌写入命令行参数或 Git。

## 通用协议
- `POST /v1/search`：`{"query":"影片名"}` → `{"items":[{"title":"影片名","name":"资源名","year":2024,"resolution":1080,"ref":"opaque"}]}`。
- `POST /v1/resolve`：`{"ref":"opaque"}` → `{"magnet":"magnet:?xt=urn:btih:..."}`。
- 鉴权：`Authorization: Bearer <独立客户端令牌>`。
- 401：更新授权；410：标识过期，重新搜索；422：缩小关键词；429：稍后重试。
- 客户端仅接受规定的资源字段，不透传 `path`、`raw_url` 等额外信息。

网关入口和公开协议必然可观察；保护的是私有上游与实现，不承诺无法复制授权返回的数据。
