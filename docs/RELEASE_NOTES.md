# v0.3.0 — 全新界面

产品更名为 Watching Everything，首页标语「从这开始你的私人影音库」。

- 界面整体重做：苹果官网式简洁排版，思源黑体，无图片和装饰堆料。
- 动效：换页标题依次浮起、列表错落进场、导航指示条滑动、弹窗和提示条进出；后台刷新不触发动效，修复了切页闪烁和下载页周期性闪动。
- 找片：搜索可取消、显示已用时间；结果按影片分组、按画质筛选；「存入 115」后状态保持，不会重复提交。
- 豆瓣片单：默认只看还没找到资源的条目，可筛选；从片单点「搜索资源」自动按年份选中影片。新增海报缓存接口 `/api/posters/{subject_id}`。
- 片库：自动整理带网址广告的文件名，小文件折叠；浏览器后退逐层返回。
- 下载：按需要处理、进行中、已完成分组，显示进度百分比。
- 应用内确认弹窗、键盘操作（⌘K、/、Esc）与读屏标签；手机端适配。
- 55 项自动化测试通过。

# v0.1.0 — Watching Everything

首个可独立部署的版本：Web 与 CLI 共用本地后端，把自己的资源源、豆瓣公开片单、CD2 与 115 下载流程连接起来。

包含 AList 兼容搜索、JSON 目录、磁力/种子导入与导出、CD2 离线任务、持久队列、防重复提交、下载完成后的媒体文件验证、豆瓣基线和增量订阅。Docker 一键部署，数据保存在自己的设备上。

没有内置资源站或共享私人接口。115 需先在用户自己的 CD2 中绑定。

22 项自动化测试和隔离端到端测试通过。真实 115 下载未实测；验收网络访问豆瓣返回 418，不能保证公开片单可用。具体范围见 `docs/VERIFICATION.md`。这是初始版本，建议先用自己的测试目录验证连接与任务流程。
