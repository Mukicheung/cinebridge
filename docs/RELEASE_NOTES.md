# v0.1.0 — 片桥 CineBridge

首个可独立部署的版本：Web 与 CLI 共用本地后端，把自己的资源源、豆瓣公开片单、CD2 与 115 下载流程连接起来。

包含 AList 兼容搜索、JSON 目录、磁力/种子导入与导出、CD2 离线任务、持久队列、防重复提交、下载完成后的媒体文件验证、豆瓣基线和增量订阅。Docker 一键部署，数据保存在自己的设备上。

没有内置资源站或共享私人接口。115 需先在用户自己的 CD2 中绑定。

22 项自动化测试和隔离端到端测试通过。真实 115 下载未实测；验收网络访问豆瓣返回 418，不能保证公开片单可用。具体范围见 `docs/VERIFICATION.md`。这是初始版本，建议先用自己的测试目录验证连接与任务流程。
