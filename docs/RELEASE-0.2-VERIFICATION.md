## 真实豆瓣与下载边界
公开分页真实返回 188 条，页面标注 200 条；同步器已完整遍历分页并识别差异，188 条均有标记日期。程序不把无法公开读取的条目伪称为已同步。

历史条目不批量下载。首次基线建立后，新增且能确认标记日期的条目可进入自动匹配；缺日期、首次同步同日及不能精确匹配的资源需要人工选择。

之前的真实 Sintel 下载已验证文件存在。本轮没有擅自修改用户豆瓣想看来制造新增事件；“用户在豆瓣新增一部后真实下载完成”尚无新增线上样本。定时同步和后续真实结果可在豆瓣片单、下载页面查看。

## 接入方式
本机页面免登录。云端检索按独立授权文件接入，支持单独撤销、轮换、到期；当前是邀请发放，没有匿名注册。用户也可连接自己的资源源。公开发行包不包含可直接滥用的共享授权。
